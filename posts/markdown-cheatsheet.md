这是一篇常驻速查文，写文章忘了语法就回来看。

## 基础语法

```markdown
# 一级标题
## 二级标题

**加粗** *斜体* ~~删除线~~ `行内代码`

- 无序列表
- 无序列表

1. 有序列表
2. 有序列表

> 引用一段话

[链接文字](https://example.com)
![图片描述](/images/xxx.png)
```

## 代码块

用三个反引号包裹，标注语言即可高亮：

```js
function hello(name) {
  return `Hello, ${name}!`;
}
```

## 表格

| 功能 | 语法 |
|------|------|
| 表格 | `\|` 分隔单元格 |
| 对齐 | `:---` 左对齐，`---:` 右对齐 |

## 写作建议

1. 一篇文章只讲一个主题
2. 开头三句话让读者知道「这篇文章能解决什么问题」
3. 多用小标题和列表，少写大段文字

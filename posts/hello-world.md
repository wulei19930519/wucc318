欢迎来到我的博客！这是第一篇文章，也是这个站点的起点。

## 为什么要写博客

- **沉淀**：很多想法想的时候很清楚，过两周就忘了。写下来才能倒逼自己理清逻辑。
- **分享**：踩过的坑写出来，别人可以少踩一遍；将来自己回头翻也省事。
- **慢思考**：社交平台是碎片输出，博客是完整表达。

## 这个站是怎么搭的

整站是一个极简的静态博客：

- 文章用 Markdown 写，带 frontmatter（标题、日期、标签、摘要）
- 一个 Node 脚本负责把 Markdown 渲染成 HTML，生成首页、标签页、归档页、RSS 和 sitemap
- 托管在 Cloudflare Pages，push 到 GitHub 就自动发布

没有数据库、没有服务器，静态文件 + CDN，够快也够稳。

## 写作约定

- 文章放在 `posts/` 目录，文件名即链接（或用 `slug` 指定）
- `draft: true` 的文章不会发布
- 标签会自动聚合到标签页

接下来会不定期更新，欢迎 RSS 订阅。
